# World capitals dataset attribution

`world-capitals-v1.jsonl` is derived from the `mledoze/countries` database at commit
`6031f5df137c41c76d180c55a0782185ae3ed05b`:

https://github.com/mledoze/countries/tree/6031f5df137c41c76d180c55a0782185ae3ed05b

The upstream database is licensed under the Open Database License 1.0 (ODbL-1.0). The derived
country/capital database in this directory is distributed under the same database license. ARLab's
code remains Apache-2.0.

Country scope is the 193 UN member states plus the two UN observer states, Palestine and the Holy
See. Synthetic prompt wording is generated locally. Multi-capital and special-status cases are
curated as role-labelled overrides; related government seats are retained as metadata.
